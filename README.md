#Cara Menjalankan#
-Clone repository ini.
-Buka file index.html di browser.
-Klik menu Pengaturan API Key, lalu tempel API key OpenWeatherMap.
-Simpan API key, kemudian cari nama kota yang diinginkan.

##Catatan##
API key OpenWeatherMap bisa didapat gratis dengan mendaftar di openweathermap.org. API key tidak ditulis di dalam kode, tetapi disimpan di LocalStorage browser masing-masing pengguna.
